# Kapwing

> Kapwing is a browser-based, AI-powered video creation platform used by 30+ million creators and creative teams to generate, edit, caption, translate, and repurpose video from a single prompt. Its developer surface is the Kapwing Plugin API — an official npm package for building whitelisted plugins that add media to the Kapwing editor canvas.

Kapwing is a company profile in the API Evangelist network. It is a media / video-editing SaaS (San Francisco, CA) with no public REST API; developer integration is via the client-side Plugin API.
